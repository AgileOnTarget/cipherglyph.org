CREATE A GLYPH

Type a message and the page draws CipherGlyphs. The GLY1 payload is shown as hex, the symbol stream is copyable, and the receipt exports as a PDF. The story and HPP context now live on the About page.

Compose

0 of 80 bytes

The page stops at 80 bytes. That is 0 to 46 letters: A-Z, space, comma, period. BadCoin, Dogecoin, and Bitcoin use the same GLY1 message budget. Lowercase is stored as uppercase.

Sheet size is locked for the 80-byte ceiling: the full 46-letter message renders as a compact 10-column sheet.

Glyph keyboard

Each tap appends a letter to the message.

Glyph sheet

Saves a local receipt: the Glyphs, the message, the stream, the hex, the BadCoin address, and any transaction fields this page actually has. The first Glyph prints its txid. Other messages stay Txid: none.

Code grammar: SHAPE + TICKS + DOT (for example COR2L). SPACE for space, DOT3 for period, DOT2 for comma. Teaching cipher, not a lock.

INSCRIBE WITH YOUR WALLET

      
BadCoin wallet handoff is active when the Chrome extension is loaded. Create the Glyph, choose the BadCoin address, then open the wallet to fund, sign, and broadcast.

      
This page builds the GLY1 payload and sends it to the wallet. The wallet owns the transaction flow. No treasury, no site-side signing, no balance reads from this page.

      
Dogecoin and Bitcoin use the same 80-byte GLY1 payload. Their wallet handoffs come after the BadCoin path is stable.
