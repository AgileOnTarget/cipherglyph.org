Compose

0 of 80 bytes

The page stops at 80 bytes. That is 0 to 46 letters: A-Z, space, comma, period. Same OP_RETURN Bitcoin and Dogecoin already relay. Lowercase is stored as uppercase. Caesar and Vigenere change the drawing, not the bytes.

Glyph keyboard

Each tap appends a letter to the message.

Glyph sheet

Saves a local receipt: the Glyphs, the message, the stream, the hex, the BadCoin address, and any transaction fields this page actually has. The first Glyph prints its txid. Other messages stay Txid: none.
