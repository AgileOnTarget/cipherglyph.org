WHAT THIS IS

CipherGlyph is a geometric alphabet by Tom Friend. Each letter is one Glyph. BadGlyph stores the letters on BadCoin. This page teaches the writing system. It does not inscribe them.

  • 1. BASE SHAPE Which group of letters. Nine shapes.
  • 2. TICK COUNT Position inside the group. One, two, or three ticks.
  • 3. DOT SIDE Right for a vowel, left for a consonant. Redundant on purpose so a mis-copied Glyph shows itself.

Nine shapes, three tick counts, two sides. Fifty-four slots for twenty-six letters. Type a sentence. The page draws Glyphs. The Glyphs decode back to the sentence.

This is a teaching cipher, not a lock. Plain, Caesar, and Vigenere are classical classroom ciphers. Vigenere was broken by Kasiski in 1863. CipherGlyph is not a security system.

To prepare a message for BadCoin, use the BadGlyph page. Public HPP inscription is coming soon. A real inscription needs a real txid.
